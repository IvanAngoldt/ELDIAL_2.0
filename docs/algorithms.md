# Алгоритмы автоматизированных функций ElDial

## 1. Ввод параметров моделирования

1. Пользователь заполняет форму (мембрана, раствор, процесс, граничные условия).
2. `ParameterValidator` проверяет диапазоны значений.
3. `ParameterInputService.parse_form()` формирует `SimulationParameters`.
4. Данные сохраняются в таблицу `parameters` (через `storage`).
5. Параметры передаются вычислительному модулю.

**Реализация:** `eldial/modules/parameters/`

## 2. Моделирование электромембранного процесса

1. Получение параметров расчёта из БД или формы.
2. Инициализация `ElectromembraneModel` и `NernstPlanckSolver`.
3. Решение уравнений переноса (схема Кранка-Николсона).
4. Расчёт плотности тока, степени деминерализации, энергопотребления.
5. Сохранение в `model_results` и `time_series_data`.

**Реализация:** `eldial/modules/computation/engine.py`, `eldial/modules/math_model/`

## 3. Анализ результатов моделирования

1. Выбор расчёта пользователем.
2. Извлечение данных из `model_results`.
3. Формирование таблиц (`ResultsTableBuilder`).
4. Построение графиков (`ChartBuilder`).
5. Отображение в окне результатов.

**Реализация:** `eldial/modules/visualization/`

## 4. Формирование отчёта

1. Выбор расчёта и разделов отчёта.
2. Извлечение параметров и результатов.
3. Формирование таблиц и графиков.
4. Генерация документа (TXT/PDF).
5. Сохранение в каталог `reports/output`.

**Реализация:** `eldial/modules/reporting/generator.py`

## 5. Уравнения математической модели

Уравнение Нернста-Планка для потока иона:

```
J = -D·∇C - (z·F·D·C)/(R·T)·∇φ
```

Плотность тока:

```
j = z·F·J
```

Численная схема: неявный метод Кранка-Николсона по пространственной координате канала мембранного элемента.
