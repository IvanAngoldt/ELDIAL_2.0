# Архитектура программной системы ElDial

## 1. Общие сведения

Программная система ElDial построена по **модульной архитектуре** с разделением на слои:

- **Presentation** — модуль `ui`
- **Application** — `parameters`, `computation`, `reporting`
- **Domain** — `domain/entities.py`
- **Infrastructure** — `storage`, `visualization`

## 3. Описание модулей

### 3.1 Модуль пользовательского интерфейса (`eldial.modules.ui`)

Обеспечивает взаимодействие пользователя с системой: главное меню, окна создания проекта, ввода параметров, просмотра результатов, формирования отчёта.

### 3.2 Модуль ввода параметров (`eldial.modules.parameters`)

Реализует алгоритм ввода и валидации параметров моделирования. Подготавливает структуру `SimulationParameters` для передачи вычислительному модулю.

### 3.3 Модуль математической модели (`eldial.modules.math_model`)

Содержит уравнения переноса (Нернст-Планк), решатель `NernstPlanckSolver`, модель `ElectromembraneModel` для расчёта концентраций, плотности тока и эффективности.

### 3.4 Модуль выполнения вычислений (`eldial.modules.computation`)

`ComputationEngine` управляет жизненным циклом симуляции: запуск, контроль статуса, сохранение в `model_results`.

### 3.5 Модуль хранения данных (`eldial.modules.storage`)

SQLAlchemy ORM, репозитории, подключение к PostgreSQL с резервным режимом SQLite.

### 3.6 Модуль визуализации (`eldial.modules.visualization`)

Matplotlib-графики, Pandas-таблицы, экспорт CSV/PNG.

### 3.7 Модуль формирования отчётов (`eldial.modules.reporting`)

Генерация текстовых и PDF-отчётов по шаблону ГОСТ 7.32-2017.

## 4. Объектная модель

| Класс | Назначение |
|-------|------------|
| `User` | Пользователь системы |
| `Project` | Проект моделирования |
| `SimulationParameters` | Параметры расчёта |
| `SimulationRun` | Запуск эксперимента |
| `ModelResult` | Результаты в `model_results` |
| `TimeSeriesPoint` | Точка временного ряда |

## 5. Конфигурация

Файлы: `config/settings.yaml`, переменные окружения с префиксом `ELDIAL_`.
