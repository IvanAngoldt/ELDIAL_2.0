# ELDIAL-PY

Реконструкция программы **ELDIAL** (электродиализное обессоливание) на Python с
удобным консольным интерфейсом ввода/вывода.

Оригинал — консольная программа MS-DOS. Эта версия
воспроизводит расчётное ядро (2D конвективная электродиффузия в камере
обессоливания) и формат вывода, добавляя сервисные расчёты, экспорт и
автоподбор параметров.

## Возможности

- Расчёт профиля концентрации `C(X)`, среднерасходной концентрации `cdav`,
  плотностей тока (`i`, `iav`, `iint`) и толщин диффузионных слоёв вдоль канала.
- Чтение/запись входных данных в формате `Eldial.DAT`.
- Полный текстовый отчёт в стиле оригинала ELDIAL + компактная сводная таблица.
- Сервисные расчёты: пересчёт `Y ↔ длина`, скорость, производительность,
  число камер, предельный ток (Пирс, Левек).
- Автоподбор безразмерной длины `Y` под заданную степень обессоливания.
- Экспорт результатов в CSV.

## Запуск

Зависимостей нет (только стандартная библиотека Python ≥ 3.9).

```bash
python main.py
```

или как модуль:

```bash
python -m eldial
```

Откроется интерактивное меню. По умолчанию данные читаются из
[`data/Eldial.DAT`](data/Eldial.DAT).

## Сборка исполняемого файла (.exe)

Собрать автономную версию (исполняемый файл + папка `data/`, без установки Python):

```bash
pip install -e ".[build]"   # установить PyInstaller
python build.py
```

Результат — папка `dist/Eldial_2.0/`:

```
Eldial_2.0/
├── Eldial(.exe)        # исполняемый файл
├── core/               # служебные файлы рантайма
└── data/Eldial.DAT     # входные данные (редактируются пользователем)
```

Запуск: открыть `Eldial.exe` (Windows) или `./Eldial` (macOS/Linux). Программа
читает и пишет данные/отчёты в папку `data/` рядом с собой.

> **Важно:** PyInstaller не делает кросс-компиляцию. Чтобы получить `Eldial.exe`
> для Windows, запускайте `python build.py` **на Windows**. На macOS/Linux
> получится бинарник под соответствующую систему.

## Модель

Безразмерные переменные `C=c/c0`, `X=x/h ∈ [0,1]`, `Y=yD/(v̄h²)`:

```
V(X)·∂C/∂Y = ∂²C/∂X²
∂C/∂X|₀ =  I·(Tna − tn)     (анионообменная мембрана, X=0)
∂C/∂X|₁ = −I·(Tpc − tp)     (катионообменная мембрана, X=1)
C(Y=0, X) = 1
I = dpsi / [ 2·tp·tn·( rac + ∫₀¹ dX/C + 1/cb ) ]
cdav = ∫₀¹ C·V dX
```

Численно: неявная маршевая схема по `Y` (backward Euler) + прогонка по `X`.
Профиль концентрации линеен по току `C(X; I) = A(X) + I·B(X)`, поэтому ток в
сечении находится надёжно — монотонным поиском корня уравнения `I = dpsi/R(C)`
на отрезке `[0, I_lim]`, без хрупкой итерации с усреднением.

**Связь тока с напряжением.** `I = (dpsi − ΔE) / R(C)`, где `R` — омическое
сопротивление (мембраны + раствор + камера концентрирования), а `ΔE` — ЭДС
концентрационной поляризации (диффузионный/доннановский потенциал ∝ `ln` отношений
концентраций, ф-ла 5.16). В источнике замкнутая форма `ΔE` (ф-ла 5.33) не приведена,
поэтому она аппроксимирована с одним эффективным коэффициентом `EMF_COEF`,
откалиброванным по одной точке (задача 1, `dpsi=10`); он независимо воспроизводит
омические точки задач 2 и 3. На входе (`C ≡ 1`) `ΔE = 0`, поэтому входной ток —
чисто омический. `EMF_COEF = 0` отключает поправку.

**Предельный режим.** Концентрация у мембраны ограничена снизу полом
`C_FLOOR = 1e-4` (в выводе — `0.0001`). Физический смысл: модель ELDIAL
(постоянные числа переноса, электронейтральность раствора) справедлива только до
предельного состояния, когда пристеночная концентрация ещё положительна. Чистый
ноль означал бы выход за область применимости. Когда напряжение требует тока выше
предельного, ток «садится» на полку `I_lim` (пристеночная концентрация — на пол),
профиль остаётся гладким и монотонным вдоль канала. На полке `ΔE` на ток не влияет.

## Валидация

Тесты воспроизводят эталонные задачи из методички:

| Задача | Условие | Эталон | ELDIAL-PY |
|--------|---------|--------|-----------|
| 1 | степень 60 %, `dpsi=10` (омика) | `Y = 0.25` | `Y ≈ 0.25` |
| 1 | степень 60 %, `dpsi≥40` (полка) | `Y = 0.15` | `Y ≈ 0.15` |
| 2 | `cd0=0.01, dpsi=60`, степень 50 % | `Y = 0.109` | `Y ≈ 0.109` |
| 3 | степень 80 %, `dpsi=10/20/30` | `Y = 0.41/0.30/0.29` | `Y ≈ 0.41/0.30/0.29` |
| 6 | профиль `C(X)` при `dpsi=100, T=0.95` | `cdav = 0.5961`, пол `C(1)=0.0001` | совпадает (~1–2 %) |
| 7 | степень 80 % (полка) | `Y = 0.29–0.3` | `Y ≈ 0.29` |

Дополнительно проверяется входной ток (`i = 29.45` для `dpsi=80, cd0=0.01`) и прямое
сравнение профилей `C(X)`, `cdav`, `i` с выводом оригинального ELDIAL (`dpsi=40/60/80`)
в области до предельного состояния — совпадение ≤0.2 %.
